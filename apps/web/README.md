# Web App Notes

The frontend now lives inside the workspace at `apps/web` and talks to the Express API in `apps/server`.

Use the root workspace commands for setup and local development:

- `pnpm install`
- `pnpm dev`

Environment variables for this app live in `apps/web/.env.local`. Start from `apps/web/.env.example`.

For full setup details, use the root [README](../../README.md).
